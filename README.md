# UNSORTED

A local-first infinite canvas for thoughts, drawings, images and beautiful chaos.

## Run locally

Requirements:
- Node.js 20+

Then:

```bash
npm install
npm run dev
```

Open http://localhost:3000

## What is included

- Infinite canvas
- Pan and zoom
- Text
- Sticky notes
- Freehand drawing
- Shapes
- Arrows
- Images
- Links
- Drag / resize / rotate
- Undo / redo
- Local browser persistence
- JSON export/import
- No login
- No database
- No backend

The canvas is intentionally not organized. The mess is the product.

## Data

The canvas is stored locally by tldraw/browser persistence. Export a JSON backup periodically if the canvas becomes important.
